# Шың — магистратураға дайындық

Магистратураға кешенді тестілеуге (КТ) қазақ тілінде дайындалуға арналған статикалық веб-қолданба: алгоритмдер мен деректер құрылымы, деректер қоры, ағылшын тілі және оқуға дайындығын анықтау тесті.

## Мүмкіндіктер

- 29 нұсқа, 61 жиынтық, әр сұраққа қазақша түсіндірме
- Жаттығу және емтихан режимдері, таймер, сұрақтар картасы, белгілер
- Ресми бағалау ережесі (бір жауап — 1 балл; бірнеше жауап — 2/1/0 балл)
- Қателермен жұмыс және аралықпен қайталау
- Карточкалар, сұрыптау күрделілігі кестесі, ағылшын синонимдері, сұрақтар қоры
- Статистика, жарық/қараңғы тақырып, мобильді нұсқа
- ЖИ түсіндірмесі (өз Groq кілтіңізбен)

Барлық прогресс тек браузердің `localStorage`-інде сақталады.

## Іске қосу

Құрастыру қажет емес — кез келген статикалық сервер жеткілікті:

```bash
python3 -m http.server 8000
```

Vercel-ге қосымша баптаусыз шығады (Framework: Other, түбір каталог).

## Құрылым

- `index.html`, `css/`, `js/` — қолданба
- `data/` — сұрақтар жиынтықтары (`Shyn.addSet(...)`)
- `media/` — ағылшын тілі тыңдалымының аудиосы
- `tools/`, `tr/` — деректерді құрастыру және аударма құралдары (сайтқа шықпайды)

Деректер [Placebek/kt_test](https://github.com/Placebek/kt_test) жобасынан алынып, қазақ тіліне аударылды; 28–29-нұсқалар сынақ тестілеу фотоларынан жиналды (кілттері талдау арқылы анықталған).

## Басты экранға орнату (PWA)

Сайт қолданба ретінде орнатылады (`manifest.webmanifest`, `icons/`) және интернетсіз жұмыс істейді (`sw.js`).
Файлдарды өзгерткен соң service worker-ді қайта жасаңыз, сонда пайдаланушыларға жаңа нұсқа жетеді:

```bash
python3 tools/gen_sw.py
```
